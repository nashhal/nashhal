# نهشل | Nashhal

منصة إخبارية تركز على أخبار ومستجدات الجنوب، مع توجه واضح نحو التغطية الموثقة والمستندة إلى المصادر.

## أقسام المستودع

| المسار | الدور |
|---|---|
| `index.html` | الواجهة الرئيسية للموقع الإخباري |
| `scripts/fetch_news.py` | تحديث الأخبار من خلاصات RSS المسموح بها |
| `ai/site/` | واجهة Nashhal AI العربية |
| `ai/src/` | حزمة الذكاء الاصطناعي والاسترجاع والـAPI |
| `ai/api/` | خدمة API وبوابة النموذج |
| `ai/configs/` | إعدادات النماذج والتدريب والتقييم |
| `ai/data/` | مخططات البيانات وعينات الـbenchmark فقط |
| `ai/docs/` | توثيق اختيار النموذج وتصميم RAG |
| `ai/deploy/` | ملفات التشغيل والنشر |
| `ai/tests/` | الاختبارات الآلية |
| `.github/workflows/` | جميع GitHub Actions |

## النشر

GitHub Pages هو نقطة النشر الموحدة للمستودع. الواجهة الرئيسية تبقى في الجذر، بينما Nashhal AI متاح تحت `ai/site/` ويدخل عبر `ai.html`.

## Nashhal AI

المشروع مبني على مبدأ **Evidence First**: الاسترجاع من المصادر، حفظ provenance، benchmark قابل للتكرار، ثم توليد الإجابة. الأوزان الكبيرة والبيانات الواسعة لا تُخزّن داخل Git.

## مبدأ مهم

المستودع لا يحتوي على مفاتيح مزودي النماذج. أي مفاتيح أو أسرار يجب أن تبقى في مدير الأسرار الخاص ببيئة التشغيل.
